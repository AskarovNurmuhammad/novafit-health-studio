# ⚡ NovaFit Studio Pro

An all-in-one, intelligent **Fitness, Macro Nutrition, Workout OS & Health Analytics Web Application** built with **React 19, TypeScript (TSX), and Tailwind CSS v4**.

![NovaFit Studio Banner](https://images.unsplash.com/photo-1517838277536-f5f99be501cd?auto=format&fit=crop&w=1200&q=80)

---

## ✨ Features

- 🥗 **Macro Nutrition & Calorie Balance OS**:
  - Live animated SVG circular progress rings for Daily Calories, Protein, Carbs, and Fats.
  - Calculation of Net Calorie Balance (`Logged Calories - Active Workout Burn`).
- 🥑 **Meal Diary & Natural Foods Database**:
  - Meal sections: Breakfast, Lunch, Dinner, and Snacks.
  - Searchable database of 25+ natural whole foods with gram-precise serving sliders and real-time macro calculation.
- 🏋️ **Interactive Workout Studio & Live Rest Interval Timer**:
  - Pre-built full routines (Push Power, Pull Strength, Leg Titan, Full-Body HIIT Burner).
  - **Live Workout Mode**:
    - Stopwatch tracker for overall session duration.
    - Customizable countdown Rest Timer (30s, 60s, 90s, 120s) with Web Audio sound beeps.
    - Per-exercise sets & reps completion tracking.
    - Confetti celebration upon finishing workout.
- 💧 **Interactive Water Tracker**:
  - Animated visual water flask with wave fill effect based on daily goal (ml).
  - Quick-log buttons (+250ml glass, +500ml bottle, +1000ml jug).
- ⚖️ **Scientific Body Metrics & TDEE Calculator**:
  - Built-in Mifflin-St Jeor formula calculating BMR, TDEE, optimal cutting/bulking calorie deficit/surplus, and personalized macros.
- 📈 **Weight Trend & BMI Analytics**:
  - SVG interactive line chart tracking weight history against user's goal target.
  - Real-time BMI calculation & classification badge.
- 🏆 **Daily Habits & Streak Gamification**:
  - Daily discipline checklist (Protein target, Water goal, Steps, Workout, Sleep).
  - Unlocked achievement badges and streak fire counter.
- 🌓 **High-Contrast Dark & Light Mode**:
  - Clean, eye-pleasing theme tailored for maximum contrast and zero washed-out elements.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Effects**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Audio**: Native HTML5 Web Audio API (Rest Timer Beeps)

## 🚀 Quick Start

### Installation

```bash
# Clone the repository
git clone https://github.com/AskarovNurmuhammad/novafit-health-studio.git

# Navigate to project directory
cd novafit-health-studio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
